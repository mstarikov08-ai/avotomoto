# АвтоМотоТур / AutoMotoTour / 汽车摩托旅游

Мультиязычный лендинг Общенациональной ассоциации Автомототуризма и караванинга.

## О проекте

Сайт ориентирован на:
- молодежь — бюджетные маршруты, программы, конкурсы;
- иностранных путешественников — информация о поездках по России на английском и китайском.

## Языки

- Русский (RU)
- English (EN)
- 中文 (ZH)
